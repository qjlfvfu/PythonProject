# Python Project - Система управления продуктами и категориями

Проект для управления продуктами и категориями с возможностью загрузки данных из JSON файлов.

## 📋 Описание

Проект представляет собой систему для работы с продуктами и категориями, включая:
- Создание и управление продуктами
- Организацию продуктов по категориям
- Загрузку данных из JSON файлов
- Автоматический подсчет статистики
## 🏗️ Структура проекта
PythonProject/
